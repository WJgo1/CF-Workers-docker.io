🔍 Markdown Reader 诊断工具

直接双击本文件打开，点下方按钮检测。

📂 必须的目录结构

请对照检查你的文件夹是否是这样的结构：

markdown-reader\ ├─ index.html ├─ start.bat ├─ check.html ├─ css\ │ └─ style.css ├─ js\ │ └─ app.js ├─ libs\ │ ├─ marked.min.js │ ├─ highlight.min.js │ ├─ highlight-github.css │ └─ highlight-github-dark.css └─ examples\ └─ 使用指南.md

🆘 常见原因

  1. 只复制了 index.html 一个文件：需要把整个 markdown-reader 文件夹复制过去，不能只复制单个文件
  2. 子目录没复制：libs/、js/、css/ 这三个文件夹一个都不能少
  3. 文件损坏：从浏览器下载时可能不完整（marked.min.js 应该 ~35KB，highlight.min.js 应该 ~122KB）
  4. Windows 隐藏了扩展名：比如实际文件名是 marked.min.js.txt 但你看不到 .txt

🛠️ 最快解决方案

如果你电脑有 Python（Win10/11 一般自带），直接双击 start.bat，绕开 file:// 协议。
