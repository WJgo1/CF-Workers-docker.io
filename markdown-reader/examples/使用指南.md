# Markdown 阅读器 使用指南

欢迎使用 **Markdown 阅读器**！这是一个轻量级、功能丰富的本地 Markdown 阅读工具。

## ✨ 主要特性

- 🚀 **极速启动** — 纯前端应用，双击即用
- 🌓 **明暗主题** — 支持亮色/暗色主题切换
- 📁 **目录浏览** — 支持打开文件夹，侧边栏浏览文件树
- 🎨 **代码高亮** — 内置 highlight.js，支持多种编程语言
- 📑 **自动目录** — 右侧自动生成文档目录导航
- 🔍 **文档搜索** — 支持在文档内搜索关键词
- 📝 **导出 HTML** — 一键导出为独立 HTML 文件
- 🖱️ **拖拽支持** — 直接拖拽文件到窗口即可打开
- ⌨️ **快捷键** — 丰富的键盘快捷键支持

## 🚀 快速开始

### 打开单个文件

1. 点击工具栏的 **"打开文件"** 按钮
2. 选择你的 `.md` 或 `.markdown` 文件
3. 开始阅读！

### 打开文件夹

1. 点击工具栏的 **"打开文件夹"** 按钮
2. 选择一个包含 Markdown 文件的文件夹
3. 左侧会显示文件树，点击任意文件即可阅读

### 拖拽打开

直接将文件或文件夹拖拽到窗口中即可。

```python
def fibonacci(n):
    """计算斐波那契数列"""
    if n <= 1:
        return n
    a, b = 0, 1
    for _ in range(n - 1):
        a, b = b, a + b
    return b

print([fibonacci(i) for i in range(10)])
```

## 🎨 自定义

### 修改主题

主题配置在 `css/style.css` 文件的 CSS 变量中：

```css
:root {
    --accent-color: #0969da;  /* 强调色 */
    --font-size-base: 16px;   /* 基础字号 */
}
```

### 修改字体

可以在 CSS 中修改 `--font-family` 变量来使用自定义字体。
